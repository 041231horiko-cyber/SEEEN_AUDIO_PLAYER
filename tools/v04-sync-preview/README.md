# SEEEN V04 STEP 01.3 · Soft Reflection

## ZIPの開き方

1. ZIPを展開します。中の `audio/` に照合済みの元音源4本、`analysis/` にSTEP 01の解析JSON4本が入っています。
2. 展開したフォルダで `python3 -m http.server 3000 --bind 127.0.0.1` を実行し、同じマシンのブラウザで `http://127.0.0.1:3000/sync-preview.html` を開きます。ブラウザでSHA-256照合を行うため、HTMLを直接ダブルクリックする方式ではなくlocalhostで開いてください。
3. 音源を選択し、SHA-256の照合が終わってから「再生」を押します。シークバーの緑が調整後の直接音、橙が元の反響候補です。
4. 候補表の時刻か「前のノック」「次のノック」を押すと、候補の0.25秒前へ移動します。一時停止している場合は「再生」を押します。全体オフセットと個別の補正はそれぞれ±500 msで、正の値は粒子を遅らせます。
5. 誤検出や反響の判定、聞き取った検出漏れ候補、補正値は「確認結果をJSONで保存」で持ち出せます。調整値はページ内に保持され、分析JSONには書き戻しません。

## NARROWの比較モード

BRIGHT / NARROWまたはDARK / NARROWを選ぶと、BASE、CUSHION、DECELERATION、COMBINEDを比較できます。従来の等速モードも残しています。設定値は両方のNARROW音源で共通です。「基準値に戻す」でBASEに戻せます。

| 項目 | 試作初期値 | 調整範囲 |
| --- | ---: | ---: |
| ノックから壁までの拡散時間 | 380 ms | 固定 |
| 壁到達から収束・消失までの基準時間 | 1,800 ms | 固定 |
| 反射境界距離（従来比） | 70% | 固定 |
| 追加明度減衰（比較用） | 0% | 0〜100% |
| クッション時間 | 60 ms | 0〜150 ms |
| 圧縮強度 | 5% | 0〜30% |
| 速度減衰 | 55% | 0〜90% |
| 反射開始速度（BASE比） | 100% | 50〜100% |

拡散時間・基準収束時間・境界距離は比較時に固定しています。「前版の基準値調整も使う」をオンにすると、以前と同じ範囲で試験調整できます。チェックを外すと3項目が基準に戻ります。

CUSHIONは壁の内側の近傍で、反射波の幅だけを滑らかに圧縮して戻します。既定値ではノック後380 msで始まり、410 msで圧縮が最大になり、440 msで戻ります。反射の位置や開始位相は変えず、波の時間は進み続けます。壁の外側に新たな輝度は加えません。

DECELERATIONは反射後の位相を進める時計の速度を徐々に落とします。既定の開始速度は元の設計座標で約72.5 px/s。55%では反射・収束時間は約2,483 ms、ノックから消失までは約2,863 msです。速度減衰0%はBASEに一致します。反射開始速度の調整は速度減衰が有効なときに適用します。明度の終端フェードは従来の位相式を使い、追加明度減衰は別に管理しています。

候補を選ぶと、表示オフセット込みの壁到達時刻と反響候補との差を表示します。補正なしでは壁到達380 msは反響候補の460〜585 msより80〜205 ms早く、既定のクッション終了440 msも20〜145 ms早くなります。反射成分は連続的に立ち上がるため、壁到達は比較の目安です。レビューJSONにモードと設定値が入ります。

### 追加明度減衰の調査

STEP 01.1の描画関数を基準値で実行し、Canvasに渡される粒子の平均alpha／最大alphaを比較しました。中心の常時点灯点は除いています。

| ノック後 | 0% | 50% | 100% |
| --- | ---: | ---: | ---: |
| 380 ms | .069 / .841 | .069 / .841 | .069 / .841 |
| 650 ms | .089 / .832 | .085 / .832 | .081 / .832 |
| 1,000 ms | .076 / .765 | .063 / .615 | .051 / .465 |
| 1,800 ms | .014 / .660 | .013 / .367 | .012 / .074 |
| 2,050 ms | .004 / .141 | .004 / .074 | .004 / .006 |

ゲインは反射・収束成分に掛かっています。序盤は直接波との最大値で反射の差が隠れやすく、終盤は既存のフェードと基礎明度のため平均の差が小さくなります。高輝度粒子に差は出ているため、追加減衰式はそのまま維持し、基準値を0%としました。この測定はCanvas入力値で、画面の測光や聴感評価とは異なります。

## 同期と粒子波

- フレームごとに単一のaudio要素の `currentTime` を読み、直近の直接音からの経過秒を描画へ渡します。時間が同じなら再描画を省略します。
- 二分探索と有効な波の短い走査で描画状態を求めます。中間フレームを落としても現時刻の位相に進みます。シーク時は移動先に存在する波だけを再構成します。NARROWの自然ループでは残っている前周の波を消失まで描画します。WIDEのループ境界での動作は従来どおりです。
- V03の粒子、パレット、DPR上限、Canvasのクリップと描画処理を再利用します。WIDEは既存の余弦の主ローブのみを使い、速度3.5と半径方向の減衰を維持します。波は最後のローブが外周を抜ける約4.61秒で終了します。
- NARROWの従来モードは元の `travel = age × 0.66` を使い、壁到達は約1.52秒、フェード終了は約3.32秒です。各モードは既存の反射・統合・収束式を使います。重なった波は粒子ごとに最大の明度を採用し、Canvasへの描画は一巡です。反射の幅の計算はクッション中だけ値が変わります。長い収束で同時に存在する波が増えた場合は、波形の計算回数も増えます。
- 反響候補はNARROW音源ごとの27件です。音源・解析JSONは元のバイト列を使用します。
