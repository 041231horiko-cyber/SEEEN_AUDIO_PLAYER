# SEEEN V04 STEP 01.1 · Audio Sync Preview

## ZIPの開き方

1. ZIPを展開します。中の `audio/` に照合済みの元音源4本、`analysis/` にSTEP 01の解析JSON4本が入っています。
2. 展開したフォルダで `python3 -m http.server 3000 --bind 127.0.0.1` を実行し、同じマシンのブラウザで `http://127.0.0.1:3000/sync-preview.html` を開きます。ブラウザでSHA-256照合を行うため、HTMLを直接ダブルクリックする方式ではなくlocalhostで開いてください。
3. 音源を選択し、SHA-256の照合が終わってから「再生」を押します。シークバーの緑が調整後の直接音、橙が元の反響候補です。
4. 候補表の時刻か「前のノック」「次のノック」を押すと、候補の0.25秒前へ移動します。一時停止している場合は「再生」を押します。全体オフセットと個別の補正はそれぞれ±500 msで、正の値は粒子を遅らせます。
5. 誤検出や反響の判定、聞き取った検出漏れ候補、補正値は「確認結果をJSONで保存」で持ち出せます。調整値はページ内に保持され、分析JSONには書き戻しません。

## NARROWの非対称速度を比較する

BRIGHT / NARROWまたはDARK / NARROWを選ぶと、非対称の試作と従来の等速を切り替えられます。調整値は両方のNARROW音源で共通です。

| 項目 | 試作初期値 | 調整範囲 |
| --- | ---: | ---: |
| ノックから壁までの拡散時間 | 500 ms | 100〜3,000 ms |
| 壁到達から収束・消失まで | 1,200 ms | 200〜6,000 ms |
| 反射境界距離（従来比） | 75% | 35〜100% |
| 反射波の追加減衰 | 65% | 0〜100% |

壁に到達する時刻に、拡散と収束で同じ正の速度を持たせています。既存の波形を連続した位相で描き、反射成分の明度を徐々に落とします。追加減衰0%でも既存の終端フェードが働きます。境界変更時は反射距離を再計算し、粒子の座標・大きさ・個数は維持します。

候補を選ぶと、表示オフセット込みの壁到達時刻と、反響候補との差を表示します。初期値かつ補正なしでは、ノックから500 msの壁到達目安は反響候補より最大40 ms遅く、最大85 ms早くなります。視覚の反射成分は連続的に立ち上がるため、壁到達は比較の目安です。反響候補から粒子波を追加発生させません。レビューJSONにモードと4つの設定値を記録します。

## 同期と粒子波

- フレームごとに単一のaudio要素の `currentTime` を読み、直近の直接音からの経過秒を描画へ渡します。時間が同じなら再描画を省略します。
- 二分探索と有効な波の短い走査で描画状態を求めます。中間フレームを落としても現時刻の位相に進みます。シーク時は移動先に存在する波だけを再構成します。自然ループで時刻が先頭に戻った際、前周の波はクリアされます。このプレビューではループ境界で前周の視覚的な尾を持ち越しません。
- V03の粒子、パレット、DPR上限、Canvasのクリップと描画処理を再利用します。WIDEは既存の余弦の主ローブのみを使い、速度3.5と半径方向の減衰を維持します。波は最後のローブが外周を抜ける約4.61秒で終了します。
- NARROWの従来モードは元の `travel = age × 0.66` を使い、壁到達は約1.52秒、フェード終了は約3.32秒です。非対称モードも既存の反射・統合・収束式を使います。波が重なる場合は粒子ごとに最大の明度を採用し、Canvasへの粒子描画は一巡です。
- 反響候補はNARROW音源ごとの27件です。音源・解析JSONは元のバイト列を使用します。

## 再生成と検証

アプリの基準コミットは `2eebb2a2263cd61861ea3229aba00f9fdfaeb916`、分析は `f58a744` です。STEP 01の出力が失われた場合は元の受領ZIPを使い、`tools/v04-audio/analyze.py` で再生成します。次のコマンドは分析JSON、元音源、試作ファイル、基準コミットから生成した描画用JSを、Git管理外のフォルダとZIPに出力します。

```sh
python3 tools/v04-sync-preview/build.py /path/to/SEEEN_V04_STEP01 /path/outside/repo/SEEEN_V04_SYNC_PREVIEW
node --test tools/v04-sync-preview/timeline.test.js
node tools/v04-sync-preview/verify-package.js /path/outside/repo/SEEEN_V04_SYNC_PREVIEW
```

試作コードは `tools/v04-sync-preview/` にあります。パッケージの検証は実データと試作JSを使い、音源時刻とCanvasをテスト用に制御します。Cloudブラウザのプレビュー接続がタイムアウトしたため、実再生は未確認です。耳へ届く音と表示の遅延は出力機器や端末に依存します。iPhone 7 / iOS 15での音声出力遅延と描画性能には実機確認が必要です。
