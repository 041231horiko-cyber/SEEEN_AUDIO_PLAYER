# SEEEN V04 STEP 03.3 · Melody Audio Preview

採用案「02 — Interference」と、STEP 02.1のノック波を完成音源で比較するためのプレビューです。

## Macで開く

1. ZIPを展開します。
2. ターミナルで展開したディレクトリに移動し、`python3 -m http.server 8000 --bind 127.0.0.1` を実行します。
3. ブラウザで <http://127.0.0.1:8000/melody-preview.html> を開きます。
4. 音源と比較モード、表示レイヤーを選択して再生します。「連動する範囲と平滑化」から応答を調整し、「レビューJSONを保存」で設定とその瞬間の特徴量・実効値を取得できます。

## 連動ルール

| モード | 明度 | 波長 | 2つ目の波の割合 |
| --- | --- | --- | --- |
| BASE | 30% | 80% | 50% |
| AMPLITUDE | RMSで20〜40% | 80% | 50% |
| FREQUENCY | 30% | 重心で65〜95% | 50% |
| COMBINED | RMSで20〜40% | 重心で65〜95% | 高域と低域の比で35〜65% |

速度は全モードで初期値150%です。表の値は操作パネルから調整できます。STEP 01がノックと反響の前後を補間した持続音の系列を使います。BRIGHTとDARKを合わせた5〜95パーセンタイルを丸め、RMSは −41.1〜−16.9 dBFS、重心は134〜1,645 Hz、750 Hz以上と未満のエネルギー比は −67.2〜12.3 dBで正規化します。重心は対数で割り当て、高域寄りほど波長を短くします。帯域比が高いほど2つ目の波の割合が増えます。無効な重心と比は有効な前後の値から補間します。初期平滑化は中心化した400 msの移動平均で、音源末尾と先頭をつなぎながら処理します。再生時は線形補間します。

位相は再生位置に周回済みの秒数を足して計算します。明示的なシークでは直前の波の持ち越しを解除し、移動先の再生位置から描画します。ノックの波形と粒子生成はSTEP 02.1のソースを利用し、WIDEの50 ms先行と自然ループの波の持ち越しを含みます。主旋律とノックの合成には各粒子で明度の最大値を使います。

## 再現

リポジトリで `python3 tools/v04-melody-preview/package.py <STEP02.1のZIP> <出力ZIP>` を実行します。スクリプトは基準コミットから描画関数を取り出し、元の解析と4音源のハッシュを照合します。展開先で `node verify.js` を実行すると、数値検証とCanvasの描画を省いた模擬性能計測ができます。
