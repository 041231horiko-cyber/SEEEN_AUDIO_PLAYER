# SEEEN AUDIO PLAYER · V04 STEP 02.1

このZIPは開発者・確認担当者向けです。完成AACと解析データを含みます。配布先の許可を確認してから公開してください。

## Macで開く

ZIPを展開し、ターミナルで展開先の `app` に移動してから起動します。

```sh
cd app
python3 -m http.server 3000 --bind 127.0.0.1
```

同じMacのブラウザで [http://127.0.0.1:3000/](http://127.0.0.1:3000/) を開きます。ファイルを直接開くとService Workerを検証できません。初回は `READY` 表示を待ちます。

## iPhone 7 / SE / 12での確認

許可済みのアクセス制限付きHTTPS静的ホストを用意し、`app/` の内容だけをV03と別のオリジンか、V03の配下に入らない専用の兄弟パスへ配置します。有効なTLS証明書と `.m4a` の `audio/mp4` 配信を確認します。設定変更や環境の公開は今回の作業に含んでいません。MacのループバックURLはiPhoneからアクセスできず、通常のLAN HTTPでは実用上Service Workerを検証できません。

各端末のSafariで専用URLを開き、`READY` 後に「ホーム画面に追加」でStandaloneを起動します。4音源を再生し、別音源への切替でクリックが2回鳴ること、停止・再開、速い連続選択、オフラインでの再起動と再生を確認します。最後の直接ノックは約121.980秒なので、124.700秒の周回前後で波の尾を確認できます。横向き、Safe Area、ロゴ、BRIGHT／DARKの切替も確認します。記録項目はURL、端末、OS、コミット、キャッシュ名です。

## 今回の同期仕様

- 4本の曲は受領したAAC／48 kHz／ステレオの元バイト列です。各124.700秒、4本合計15,412,822バイトです。各JSONは対応ファイル名・長さ・SHA-256と35件の直接ノック候補を持ちます。NARROWの27件の反響候補は参照情報です。
- 描画が必要とするのは現在の曲の直接ノック時刻だけです。音源の `currentTime` を二分探索で照合し、波が存在する区間だけ描画します。保持済みの反響候補や主旋律の特徴量をフレームごとに解析しません。
- WIDEはSTEP 01.3の単発波、NARROWはCOMBINEDを移植しました。反射設定は380 ms／基準1,800 ms／境界70%／追加明度減衰50%、クッション100 ms／圧縮30%、速度減衰55%／反射開始速度BASE比70%です。「前版の基準値調整も使う」がOFFでも明度減衰50%は描画に適用されていました。壁到達380 ms、反射開始速度約50.7設計px/s、反射・収束約3,547 ms、寿命約3,927 ms、クッション終了480 msです。
- 6,500／9,500粒子の座標、サイズ、Canvas解像度を維持します。同期描画は複数波の明度の最大値を固定粒子に適用します。4曲とも自然ループを含めた最大同時波数は2です。WIDEも自然ループ前の波を持ち越します。STEP 02.1ではWIDEの描画イベント時刻だけ `WIDE_KNOCK_VISUAL_LEAD_MS = 50` ms早めています。解析JSON、音源の再生位置、ノック音、NARROWの時刻は変更しません。ループ直前のイベントも描画スケジュールを補正し、前周回の波として自然に持ち越します。
- 288 msのPoint Emission、420 msのCollapse、900 msのResetと32/36/32%区間、配色補間、Soft Pressを維持します。EmissionはUIへの反応として末尾をフェードし、同期波のない区間は点に戻ります。再開途中も音源位置は進み、操作アニメーションからその時点の実波へ復帰します。STEP 06で遷移の重ね方を評価できます。
- Service Workerは22 URLを確認し、V04専用のスコープ別キャッシュだけを参照します。同一公式V03パスへの登録を拒否します。キャッシュ識別子は `seeen-v04-step02-1-v1:` です。更新失敗時も旧キャッシュを消去せず、開いている旧版ページは閉じるまで旧Workerを使います。
- Range応答は `Blob.slice()` で206を返し、音源全体のJS ArrayBufferと部分コピーの組を作りません。1要求につき最長3,970,926バイトのBlob本体は必要です。複数要求では一時領域が重なる場合があり、iOSでの実消費量は未測定です。

## 復元・検証
