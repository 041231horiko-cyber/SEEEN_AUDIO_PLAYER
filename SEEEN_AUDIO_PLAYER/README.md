# SEEEN / Exhibition Audio Player

iPhone 7（iOS 15 / Safari）向けの、展示専用オフライン音声プレイヤーです。単一の `HTMLAudioElement` だけを使い、4音源を排他的に再生します。外部API・外部ライブラリ・音質処理は使用していません。

## 現在の状態

- Phase 1: UI、再生、一時停止、先頭からの音源切替、同一音源の再選択、連続タップ対策を実装済み
- Phase 2: PWA、Service Worker、全ファイルのキャッシュ検証、Rangeリクエスト対応、欠損時の再保存を実装済み
- Phase 3: HTTPSからホーム画面へ追加したiPhone 7で、standalone起動とオフライン動作の実機検証が必要
- Phase 4: 完成した長尺4音源への差し替えとループ品質検証が必要

`audio/` 内のWAVは、完成音源と区別するための短い開発用テスト音です。展示では使用しないでください。

## Macでのローカル確認

HTMLファイルをFinderから直接開く `file://` 方式ではService Workerは動作しません。ターミナルでHTTPサーバーを起動します。

```sh
cd ~/Desktop/SEEEN_AUDIO_PLAYER
python3 -m http.server 8080
```

Safariで <http://localhost:8080> を開きます。`localhost` はService Workerの安全な開発元として扱われます。画面に `OFFLINE READY` が出てから音源を切り替えてください。

**重要:** `localhost` の例外が使えるのは、サーバーとブラウザが同じMac上にある場合です。iPhoneからMacのローカルIPアドレス（例: `http://192.168.x.x:8080`）へ接続すると、画面表示や音声再生ができても安全なHTTPS環境ではありません。Service Worker、オフライン保存、ホーム画面アプリ化の最終判定には使用せず、必ずHTTPSの公開URLで確認してください。

確認終了後は、ターミナルで `Control + C` を押してサーバーを停止します。

## 完成音源の導入

次の4ファイルを、同じ名前で `audio/` に配置します。

| 表示名 | ファイル名 |
| --- | --- |
| BRIGHT × WIDE | `bright_wide_loop.wav` |
| BRIGHT × NARROW | `bright_narrow_loop.wav` |
| DARK × WIDE | `dark_wide_loop.wav` |
| DARK × NARROW | `dark_narrow_loop.wav` |

差し替えたら、`service-worker.js` 冒頭の `CACHE_VERSION` を `seeen-audio-v6` のように必ず更新してください。同じURLのままバージョンを変えないと、端末にテスト音が残る可能性があります。旧キャッシュは再生中の音源を不意に消さないため自動削除しません。

### WAV容量について

180秒・48kHz・24bit・ステレオWAVは1本約52MB、4本で約207MBです。iOS 15のWebストレージ保持は端末状態に左右され、この容量では保存失敗やOSによる削除のリスクが高くなります。

まず完成WAVで実機テストを行い、保存が不安定な場合だけAAC（例: 256kbps、1本約5.8MB）を検討してください。AACはエンコーダ遅延によりループ境界へ無音やクリックが入ることがあるため、変換前後の波形とiPhone実機の連続ループを確認します。AACへ変更する場合は、4ファイルの拡張子に合わせて `player.js` と `service-worker.js` の両方を書き換えます。

## HTTPSでの実機導入

無料で扱いやすい方法はGitHub Pagesです。公開して問題のない音源だけを使い、公開リポジトリへこのフォルダの内容を配置します。

1. GitHubで新しいリポジトリを作成する
2. このフォルダの全ファイルをリポジトリ直下へ配置する
3. GitHubの `Settings > Pages` で `Deploy from a branch` を選ぶ
4. `main` / `/ (root)` を指定して公開する
5. 表示された `https://...github.io/.../` をiPhoneのSafariで開く

音源を公開できない場合は、アクセス制限できるHTTPSホスティングまたは会場LAN内のHTTPSサーバーが必要です。GitHub PagesはURLを知る人がファイルへアクセスできる前提です。

### iPhone 7へのインストール（3台それぞれで実施）

1. iPhoneをWi-Fiへ接続し、SafariでHTTPSの公開URLを開く（アプリ内ブラウザは使わない）。`OFFLINE READY` になるまで画面を閉じない
2. Safari下部の共有ボタンを開く
3. 「ホーム画面に追加」を選び、名前が `SEEEN` であることを確認して追加する
4. Safariを閉じ、ホーム画面のSEEENアイコンから起動する
5. Safariのアドレスバー、戻る・進む、共有などの操作バーが表示されないことを確認する。iOSのステータスバーは表示されたままでも正常
6. 4音源を1回ずつ再生し、切替、PLAY / PAUSE、`OFFLINE READY` を確認する
7. アプリを終了し、機内モードをオン、Wi-FiをオフにしてSEEENアイコンから再起動する。4音源の再生・切替と再起動後のキャッシュ状態を確認する

`OFFLINE READY` は、アプリ本体・アイコン・4音源が現在のキャッシュにすべて存在するときだけ表示されます。`RETRY` の場合はオンラインへ戻してタップします。

Safariの操作バーが表示される場合は、Safari内のタブを開いていないか確認してください。専用表示になるのはホーム画面のSEEENアイコンから起動したときだけです。以前のアイコンが残っている場合はそのアイコンを削除し、最新版をHTTPSで開いてから「ホーム画面に追加」をやり直してください。

### ホーム画面アイコンを更新した場合

iOSはホーム画面アイコンを強くキャッシュします。GitHub Pagesへの更新完了後、iPhoneのホーム画面にある既存のSEEENアイコンを一度削除してください。その後、SafariでHTTPSの公開URLを開き、`OFFLINE READY`を確認してから、共有メニューの「ホーム画面に追加」でSEEENを追加し直します。削除と再追加を行わない場合、以前のアイコンが表示され続けることがあります。

## 展示前の端末設定

- `設定 > 画面表示と明るさ > 自動ロック > なし`
- おやすみモードまたは集中モードを有効化
- 通知、着信、アラームを無効化または展示用端末から除外
- 音量を3台で揃え、音量ボタンの誤操作を防ぐ
- 自動iOSアップデートを展示期間中は避ける
- 必要に応じてアクセスガイドを設定し、アプリからの退出を防ぐ
- Lightning分岐アダプタで充電と有線出力を同時使用し、実機で数時間確認する

iOS 15のWebアプリから画面点灯を強制し続けることはできません。自動ロック設定と給電で運用してください。画面ロックやOSの割り込み後は再生が停止する場合があります。

## 実機テストチェックリスト

- [ ] 375 × 667 CSS pxで文字・ボタン・セーフエリアが欠けない
- [ ] ホーム画面のSEEENアイコンから起動するとSafariのアドレスバーとナビゲーション操作領域が表示されない
- [ ] 4音源がワンタップで再生される
- [ ] 4音源を素早く連続タップしても最後に選んだ1音源だけが鳴る
- [ ] 同じ音源を再タップすると先頭へ戻る
- [ ] PLAY / PAUSEを繰り返して状態表示が一致する
- [ ] 180秒の終端から先頭へ複数回ループする
- [ ] ヘッドホンでループ境界のクリック・無音・音量差がない
- [ ] `OFFLINE READY` 後、機内モード＋Wi-Fiオフで4音源を切り替えられる
- [ ] ホーム画面アプリを終了・再起動してもオフライン再生できる
- [ ] iPhone再起動後もオフライン再生できる
- [ ] 充電しながら有線ヘッドホンへ正しく出力される
- [ ] ケーブルの抜き差し後に出力先と再生状態を確認できる
- [ ] 画面ロック、ロック解除、アプリ復帰時の停止有無を確認する
- [ ] 8時間以上の連続再生で停止、発熱、音ずれがない
- [ ] 端末ストレージに十分な空きがある

## エラー時の復旧

1. 音が止まった場合は、選択中の音源ボタンをもう一度タップする
2. `OFFLINE RETRY` の場合はWi-Fiへ接続し、`RETRY` をタップする
3. 改善しない場合はSafariで公開URLを開き直し、`OFFLINE READY` を待つ
4. 4音源を確認後、ホーム画面アプリを終了して再起動する
5. 音が本体から出る場合は、Lightningアダプタとヘッドホンを挿し直して出力を確認する

Safari/iOSは空き容量や未使用期間などによりキャッシュを削除する可能性があり、Webアプリ側から永続保持を保証できません。展示日ごとにオンライン状態で3台の `OFFLINE READY` と機内モード再生を確認してください。
